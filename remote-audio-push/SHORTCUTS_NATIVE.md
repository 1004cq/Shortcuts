# 快捷指令（不用「获取词典」、不用开浏览器）

轮询地址会**直接返回纯文本音频 URL**（`format=url`）：

```
https://cq.imim.chat/realtime/api/poll?userId=你的ID&token=TOKEN&wait=25&format=url
```

- 有播放任务 → 返回一行 `https://...音频地址`
- 暂时没有 → 返回空
- 停止指令 → 返回 `STOP`

## 捷径步骤（简单版）

1. **重复** `9999` 次  
2. **获取 URL 内容** → 粘贴上面的轮询地址  
3. **如果**「获取 URL 内容」**有任何值**  
4. 如果里面：再 **获取 URL 内容**（URL = 上一步的文本，即音频地址）  
5. **播放声音**  
6. 运行捷径即可

不需要「获取词典 / 获取字典」。

## 后台

`/admin/remote-play` → 生成快捷指令配置 → 复制轮询 URL。
