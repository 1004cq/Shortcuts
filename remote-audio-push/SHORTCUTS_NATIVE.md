# 快捷指令（最简 · 不用「获取词典」）

轮询地址使用 **`format=file`**：有播放时接口 **302 跳转到音频文件**，捷径「获取 URL 内容」会直接得到可播的音频。

```
https://cq.imim.chat/realtime/api/poll?userId=你的ID&token=TOKEN&wait=25&format=file
```

- 有播放任务 → 跟随重定向，返回音频文件
- 暂时没有 → HTTP 204（无内容）
- 不要用旧的 `format=url` 把文字当成声音文件播放

## 捷径步骤（3 个动作）

1. **重复** `999` 次  
2. **获取 URL 内容** → 粘贴上面的轮询地址（GET）  
3. **如果**「URL 的内容」**有任何值** → **播放声音**（声音文件 = URL 的内容）  
4. 运行捷径即可

不要添加「获取词典 / 获取字典」。  
不要再添加第二个「获取 URL 内容」。

## 后台

`/admin/remote-play` → 生成快捷指令配置 → 复制轮询 URL（会带 `format=file`）。
